# Khaled Ali — Portfolio

موقع شخصي ثابت (HTML + CSS + JS) بدون أي backend — مع داش بورد بيكوميت مباشرة على GitHub.

---

## ملفات الموقع

| الملف | الغرض |
|---|---|
| `index.html` | الصفحة الرئيسية للزوار |
| `styles.css` | كل التنسيقات (سلم فونتات موحّد، RTL/LTR، responsive) |
| `script.js` | المنطق + i18n bootstrap + render الأعمال |
| `content-defaults.js` | النصوص الافتراضية (AR + EN). **لا تعدّله يدويًا** |
| `content.json` | نصوص بتعمل override على الافتراضي. **بتيتولد من الداش بورد** |
| `projects-defaults.js` | قائمة الفيديوهات الافتراضية (الأعمال). **لا تعدّله يدويًا** |
| `projects.json` | قائمة فيديوهات بتعمل override على الافتراضي. **بتيتولد من الداش بورد** |
| `admin.html` | لوحة التحكم — تبويبات: نصوص/أسعار، فيديوهات، صور |
| `github-api.js` | عميل GitHub REST API بيستخدمه الداش بورد للحفظ المباشر |
| `inline-edit.js` | overlay التعديل المباشر على الموقع (`?edit=1`) |
| `fonts/` | (احتياطي) فونتات قديمة محفوظة كنسخة احتياطية. الفونتات الفعّالة بتيجي من Google Fonts CDN |
| `khaled-hero.webp` / `khaled-hero.jpg` / `khaled-bts.webp` / `khaled-bts.jpg` | صور الـ hero و BTS |

## رفع الموقع على GitHub Pages — الدليل بالخطوات

### الخطوة ١: تجهيز Git على جهازك

لو أول مرة تستخدم Git، نزّله من https://git-scm.com وبعدين افتح Terminal واكتب:
```bash
git config --global user.name "Khaled Ali"
git config --global user.email "bebooxo7@gmail.com"
```

### الخطوة ٢: عمل ريبو جديد على GitHub

1. ادخل على https://github.com وادوس **New repository**.
2. سمّيه مثلاً `khaled-portfolio` (أو أي اسم).
3. اختار **Public** (عشان GitHub Pages يشتغل مجانًا).
4. **متعملش** check على "Add a README" (هنرفع كل حاجة بنفسنا).
5. ادوس **Create repository**.

### الخطوة ٣: رفع كل الملفات

في Terminal، روح لمجلد الموقع:
```bash
cd /path/to/khaled-site
git init
git add .
git commit -m "Initial site upload"
git branch -M main
git remote add origin https://github.com/<username>/khaled-portfolio.git
git push -u origin main
```

استبدل `<username>` باسم حسابك على GitHub.

> **ملاحظة:** الفونتات بقت بتيجي كلها من Google Fonts CDN، فمش هتقابل مشكلة الـ binary upload القديمة. أي طريقة رفع (Git CLI أو واجهة GitHub) هتشتغل صح للنصوص و الصور.

### الخطوة ٤: تفعيل GitHub Pages

1. في صفحة الريبو على GitHub، روح **Settings**.
2. من القائمة الجانبية، **Pages**.
3. تحت **Source**، اختار: `Deploy from a branch`.
4. تحت **Branch**: `main` و folder: `/ (root)` ثم **Save**.
5. استنى ١-٢ دقيقة، GitHub هيدّيك رابط زي:
   ```
   https://<username>.github.io/khaled-portfolio/
   ```

### الخطوة ٥: التأكد إن الفونتات بتشتغل

الموقع بيستخدم **Cairo** للعربي و **Inter** للإنجليزي — الاتنين من Google Fonts CDN، يعني مفيش ملفات فونت بترفعها على ريبوك. ده معناه إن الفونت هيشتغل **زي ما هو** على GitHub Pages من غير أي إعدادات إضافية.

لو حبّيت تتأكد:

1. افتح الموقع → **Developer Tools** (F12) → **Network** → فلتر **Font**.
2. ريفريش الصفحة (Ctrl+F5).
3. هتلاقي ملفات بتيجي من `fonts.gstatic.com` (وليس من ريبوك)، وكلها لازم تكون status `200`.

> **Fallback آمن:** لو في أي ظرف Google Fonts ما اشتغلش، الـ CSS فيه fallback chain على فونتات النظام (Segoe UI, Tahoma, system-ui)، فالموقع هيفضل بشكل احترافي ومقروء.

## استخدام لوحة التحكم (`/admin.html`)

اللوحة بتشتغل **في المتصفح بس** — كل التعديلات بتنحفظ مباشرة على GitHub عن طريق الـ API. مفيش backend ومفيش رفع يدوي.

### الإعداد (مرة واحدة)

1. على GitHub: روح **Settings → Developer settings → Personal access tokens → Fine-grained tokens** أو افتح الرابط ده مباشرة:
   `https://github.com/settings/personal-access-tokens/new`
2. **Token name**: مثلاً `khaled-dashboard`.
3. **Expiration**: ٩٠ يوم أو سنة (لما تخلص هتعمل واحد جديد).
4. **Repository access** → اختار "Only select repositories" → اختار ريبو الموقع.
5. **Repository permissions** → اعمل سحب لـ **Contents** → اختار **Read and write**.
6. اضغط **Generate token** ونسخ التوكن (هيظهر مرة واحدة بس!).
7. افتح `https://<your-site>/admin.html` → اضغط **🔐 إعداد GitHub** → الصق:
   - Owner: اسم حسابك على GitHub.
   - Repo: اسم الريبو.
   - Branch: `main`.
   - Personal Access Token: اللي نسخته.
   - الاسم والإيميل (اختياري) — هيظهروا على الـ commits.
8. اضغط **💾 حفظ واختبار** → لو ظهرت رسالة "تم الاتصال" بقيت جاهز.

> **التوكن بيتخزن في المتصفح بتاعك بس.** مش بيتبعت لأي حد غير github.com. أي حد فاتح المتصفح بتاعك من نفس الجهاز يقدر يستخدمه — فلو شاركت الجهاز اضغط **🗑️ مسح** في فورم الإعداد.

### تبويب "📝 النصوص والأسعار"

1. افتح `https://<your-site>/admin.html`.
2. عدّل في النصوص والأسعار اللي عايزها (في AR و EN).
3. تعديلاتك بتتحفظ تلقائيًا في المتصفح (localStorage).
4. دوس **👁️ معاينة** لمشاهدة الموقع بالتعديلات الحالية.
5. لما تكون راضي، دوس **💾 حفظ على GitHub** → الداش بورد بتكوميت `content.json` مباشرة على الريبو.
6. خلال دقيقة، GitHub Pages بيحدّث الموقع لكل الزوار.

> ولو حابب التنزيل اليدوي زي قبل (مثلاً عشان تشوف الـ JSON): زرار **⬇️ تنزيل JSON** لسه موجود.

### تبويب "🎬 فيديوهات الأعمال"

ده اللي بيخلّيك تتحكم في كل الفيديوهات في قسم "الأعمال":

1. ادوس على تبويب **🎬 فيديوهات الأعمال** فوق.
2. هتشوف كل الفيديوهات مقسّمة على ٥ أقسام: بودكاست، ريلز، يوتيوب طويل، تعليمي، أفراح.
3. **+ فيديو جديد** — يفتح فورم لإضافة فيديو:
   - **القسم**: بودكاست / ريلز / يوتيوب طويل / تعليمي / أفراح.
   - **القسم الفرعي** (للريلز فقط): عام / طبي / تعليمي / تسويقي / ذكاء اصطناعي.
   - **الاتجاه**: أفقي (16:9) أو رأسي (9:16).
   - **المنصّة (Badge)**: YouTube / Vimeo / Facebook ...
   - **رابط الفيديو**.
   - **صورة معاينة (Poster)** اختياري.
   - **العنوان والوصف والتاج بالعربي والإنجليزي**.
4. **✎ تعديل** — لتغيير أي فيديو موجود.
5. **🗑️** — لحذف الفيديو من الموقع.
6. **▲ ▼** — لتحريك الفيديو فوق وتحت في الترتيب.
7. لما تخلّص، ادوس **💾 حفظ على GitHub** → الداش بورد بتكوميت `projects.json` على الريبو مباشرة. خلال دقيقة الموقع هيتحدث.

> أو لو حابب التنزيل اليدوي: زرار **⬇️ تنزيل projects.json** برضه موجود.

### تبويب "🖼️ الصور"

ده تبويب جديد بيخليك ترفع الصور (لوجو، صور Hero/BTS، Posters للفيديوهات) مباشرة على الريبو:

1. اسحب صورة في المساحة المظللة، أو اضغط "اختار صورة من جهازك".
2. الداش بتكوميت الصورة على الريبو وهتظهر تحت في الجريد.
3. كل صورة فيها زرار **📋 نسخ المسار** عشان تنسخ اسم الملف وتستخدمه في أي مكان (هير، فيديوهات، بوسترز).
4. **🗑️ حذف** بيمسحها من الريبو نهائي.

> الصور المدعومة: JPG, PNG, WebP, SVG, GIF. حجم مفضّل أقل من 2MB. للفيديوهات لسه بنستخدم روابط يوتيوب/فيميو/إلخ.

### وضع التعديل المباشر على الموقع نفسه (`?edit=1`)

عوضًا عن إنك تفتح الداش بورد، تقدر تفتح الموقع نفسه في وضع تعديل:

1. روح على `https://<your-site>/?edit=1`.
2. هيظهر شريط أخضر تحت يمين/شمال الشاشة (حسب الاتجاه).
3. **مرّ الماوس** على أي نص — هيتحدد بإطار أخضر متقطّع وعليه زرار قلم ✎.
4. **اضغط القلم** عشان تكتب فوقه مباشرة. اضغط Enter للحفظ المؤقت أو Escape للإلغاء.
5. **مرّ على صور Hero/BTS** → اضغط "📷 رفع صورة جديدة" عشان تستبدلها (بترفع على الريبو فورًا).
6. لما تخلص، اضغط **💾 حفظ التعديلات** في الشريط — كل التغييرات بتتكوميت دفعة واحدة على `content.json`.
7. للخروج من وضع التعديل، اضغط × أو امسح `?edit=1` من الرابط.

> أول مرة تفتح ?edit=1 محتاج تعدّ GitHub من زرار ⚙️ في الشريط (نفس بيانات الداش بورد).

### ملاحظات على الفيديوهات

- لما تضيف فيديو وما تكتبش رابط، الفيديو بيظهر كـ "قريبًا" (placeholder) في الموقع.
- لو ما حطّيتش Poster (صورة معاينة)، الموقع بيستخدم تدرّج لوني افتراضي.
- لو فيديو ريلز (رأسي)، خلّي **الاتجاه = رأسي** عشان يطلع بالأبعاد الصحيحة.
- AR و EN بيتزامنوا تلقائيًا (لو اكتفيت بنسخة واحدة، التانية بتتعبّى منها).

### مزايا الداشبورد:

- 🔍 **بحث فوري** في النصوص والفيديوهات.
- 🎯 فلاتر بالقسم.
- ⚡ **حفظ تلقائي** — مش هتفقد تعديلاتك لو قفلت التاب.
- ↺ **زر إعادة تعيين** يرجّع كل حاجة للقيم الأصلية.
- 🔐 **محلي 100%** — مفيش بيانات بتروح لأي خادم خارجي.

### تنبيه أمان

`admin.html` و `?edit=1` بيظهروا للجمهور (أي حد يعرف الرابط يقدر يفتحه)، لكن:
- لحد ما حد يدخل التوكن بتاعك في فورم إعداد GitHub، الداش بورد ما تقدرش تكتب على الريبو — التعديلات بتفضل في الـ localStorage بتاعه فقط.
- التوكن نفسه بيتخزن مشفّر-Base64 في الـ localStorage بتاع المتصفح اللي عمل الإعداد. أي حد فاتح نفس المتصفح من نفس الجهاز يقدر يستخدمه — ده ليه استخدم Fine-grained PAT scoped على الريبو ده فقط بصلاحيات أقل ما يمكن.
- مش بيستخدم الـ Token إلا في طلبات `api.github.com` فقط (مش بيتبعت لأي domain تاني).

#### نصايح أمان إضافية:
- لما تخلص شغل من جهاز مش بتاعك (مثلاً جهاز صديق)، اضغط **🗑️ مسح** في فورم إعداد GitHub.
- استخدم Expiration قصيرة (٣٠-٩٠ يوم) للـ PAT.
- لو سرّب التوكن، روح على GitHub → Settings → Personal access tokens واعمل **Revoke** فورًا.
- لو حابب تخفي الداش بورد عن السيرش engines: ملف `admin.html` فيه `meta name="robots" content="noindex"` بالفعل.
- لو حابب تخفي الـ admin عن الجمهور تمامًا: أعد تسميته لاسم عشوائي (مثلاً `panel-x9k.html`) عشان مش يكون متوقع.

## بنية الـ i18n

النصوص موزّعة على ٢٢ قسم. أهم الأقسام:

- `meta.*` — title و description لـ Google و Facebook
- `nav.*` — قائمة التنقل العلوية
- `hero.*` — أول قسم في الصفحة
- `about.*` — القسم التعريفي + ٤ كروت
- `services.*` — ٨ خدمات
- `pricing.*` — ٧ باقات (e1/e2/e3 مونتاج، m1/m2/m3 تسويق، st استوديو)
- `testimonials.*` — ٣ شهادات عملاء
- `process.*` — خطوات الشغل
- `form.*` — فورم التواصل
- `footer.*` — حقوق النشر

كل مفتاح ليه نسختين: `i18n.ar[key]` و `i18n.en[key]`.
